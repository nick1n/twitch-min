twitch-min - Chrome and Opera GX

INSTALL
1. Extract the ZIP and keep the extracted folder in place.
2. Open chrome://extensions (Chrome) or opera://extensions (Opera GX).
3. Enable Developer mode, choose Load unpacked, and select the folder
   containing manifest.json.
4. Pin twitch-min in the Extensions menu, then open Twitch.

USE
Click the extension icon to change settings. Turn Enabled off to pause without
losing your choices. Enable all settings turns every option on.

All options start on except Hide top navigation bar and About & channel panels.
Click Chat to show or hide the message box without losing your draft.
Press Enter in the message box to send.

TROUBLESHOOTING
If a setting doesn't work, check that Enabled and the setting are turned on.
Make sure your browser allows twitch-min to run on Twitch, then refresh the tab.

If the popup shows an error, click Copy error details and Report the issue.
Describe what happened and how to reproduce it. If copying fails, select and
copy the displayed text manually.

UPDATE OR REMOVE
Replace the files in the same folder, then click Reload for twitch-min on your
browser's extensions page. To uninstall, click Remove; this also deletes your
saved settings.

Full guide and privacy information: https://github.com/nick1n/twitch-min
