twitch-min - Chrome and Opera GX

INSTALL
1. Extract the ZIP and keep the extracted folder in place.
2. Open chrome://extensions (Chrome) or opera://extensions (Opera GX).
3. Enable Developer mode, choose Load unpacked, and select the folder
   containing manifest.json. No build or dependency installation is needed.
4. Refresh Twitch tabs. Pin twitch-min in the Extensions menu to open settings.

USE
Each switch explains its effect. Changes apply immediately.
Enable twitch-min pauses/resumes while keeping your choices.
Enable all settings turns every option on.
More settings / Back to top scrolls the list.

All options start on except Hide top navigation bar and About & channel panels.
Chat toggles the editor without sending or losing drafts; Enter sends
normally. Disabling a switch restores that feature; pausing restores everything.

PRIVACY AND LIMITS
Runs only on HTTPS twitch.tv pages, with or without www. The only API permission
is storage, for local settings. No credentials, analytics, backend, remote scripts,
or page content uploads. Emote previews may load larger images from Twitch's CDN.
Hidden Twitch features can still run. Layouts and languages vary; signed-in-only
behavior still needs validation.

UPDATE OR REMOVE
Replace the files in the loaded folder, reload twitch-min on the extensions
page, and refresh Twitch. Keep the folder while the extension is installed.
Remove on the extension card uninstalls it and deletes saved preferences.

Full guide, known limits, and issues: https://github.com/nick1n/twitch-min
